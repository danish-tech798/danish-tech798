## 🚀 Selected work

### 🚗 [AutoGauge — Used Vehicle Valuation](https://github.com/danish-tech798/AutoGauge)

**Final-year team project** combining vehicle information and photo-based condition assessment to estimate used-vehicle prices.

**XGBoost · YOLO · SHAP · Flask · Next.js · SQLite**

<details>
<summary><b>Explore the application and technical focus</b></summary>

- XGBoost-based vehicle valuation with YOLO damage detection and condition scoring.
- SHAP-based explanations of feature contributions.
- Next.js frontend connected to a Flask API.
- Authentication, valuation history, saved vehicles, and PDF reports.

The project brings together **predictive modelling, computer vision, explainability, and web integration**. It is a team project; its repository lists the project team.

[View code, setup instructions, and limitations →](https://github.com/danish-tech798/AutoGauge)

</details>

### 🚦 [RoadSense — Indian Road Sign Detection](https://github.com/danish-tech798/RoadSense)

An academic computer vision application that identifies supported Indian road signs in uploaded photographs using a custom-trained **YOLOv8s** detector.

**Python · YOLOv8s · PyTorch · Flask · JavaScript · SQLite**

<details>
<summary><b>Explore the detector and reported evaluation</b></summary>

- Supports **85 road-sign classes**.
- Displays bounding boxes, confidence scores, and sign information.
- Includes configurable inference settings, accounts, and personal detection history.
- Documents dataset cleaning, split preparation, and evaluation limitations.

| Reported metric | Held-out result |
| :--- | ---: |
| mAP@0.50 | 97.50% |
| mAP@0.50:0.95 | 91.75% |
| Test images | 563 |

These are detection metrics on the held-out dataset, not a general accuracy guarantee. Performance on unrelated road photographs remains an improvement area.

[View code, dataset notes, and results →](https://github.com/danish-tech798/RoadSense)

</details>
