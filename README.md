## Featured projects

### AutoGauge — Used Vehicle Valuation

**Final-year team project · Machine learning + computer vision + explainability**

A vehicle valuation application that combines vehicle details with photo-based condition assessment and explains the factors behind a price estimate.

- Combines an XGBoost valuation model with YOLO damage detection and condition scoring.
- Uses SHAP to explain feature contributions to predicted prices.
- Connects a Next.js interface to a Flask API with authentication, saved valuations, history, and PDF reports.

**Stack:** Python, XGBoost, YOLO, SHAP, Flask, Next.js, React, SQLite

[Explore AutoGauge →](https://github.com/danish-tech798/AutoGauge)

### RoadSense — Indian Road Sign Detection

**Academic computer vision project · Custom-trained YOLOv8s detector**

A Flask application that detects supported Indian road signs in uploaded images and displays bounding boxes, confidence scores, and sign descriptions.

- Supports 85 road-sign classes, with configurable confidence thresholds and inference sizes.
- Includes user accounts, a detection dashboard, and personal detection history.
- Documents dataset cleaning, split preparation, evaluation results, and generalization limitations.

**Reported held-out results:** 97.50% mAP@0.50 and 91.75% mAP@0.50:0.95 on 563 test images. These are dataset detection metrics; performance on unrelated road photos remains an improvement area.

**Stack:** Python, Ultralytics YOLOv8s, PyTorch, Flask, HTML, CSS, JavaScript, SQLite

[Explore RoadSense →](https://github.com/danish-tech798/RoadSense)
